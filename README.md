# oracle-epm-automate-toolkit
Production-ready Windows batch scripts for automating routine tasks in Oracle EPBCS, FCCS, and other EPM Cloud applications using the EPM Automate CLI.

About
Maintaining an Oracle EPM Cloud environment involves dozens of repetitive tasks: daily backups, LCM exports for version control, data loads from source systems, metadata refreshes, and cube refreshes. This toolkit collects reusable Windows batch scripts to automate these tasks reliably.
Every script includes:

✅ Centralized configuration (one file to edit per environment)
✅ Timestamped logging
✅ Error handling with meaningful exit codes
✅ Email-friendly log summaries

All scripts are sanitized — they use placeholder URLs, dummy entity names, and generic structures. No client or production data is included.
